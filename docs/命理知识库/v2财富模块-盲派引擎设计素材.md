## 〇、一句话目标

把「**谁是工具(体)、谁是资源(财官)、有没有做功、能不能拿进主位、层次几档**」这条盲派求财链,变成**输入八字 → 确定性输出财富结构对象**的纯函数管线,用机主盘验收。

## 一、判定流程(可伪代码化的 7 步)

```
输入: paipan() 返回对象(四柱干支 + 藏干本/中/余 + 十神)  ← 复用现有排盘层,不重排

Step 0  归一化十神:天干十神 + 地支藏干十神,全部标到 {柱位, 干/支, 十神, 本中余}
Step 1  体用分区
          体(工具)  = 印 ∪ 比劫 ∪ 食伤  对应的干支集合
          资源(所求) = 财 ∪ 官杀          (若原局无财 → 食伤可暂当财论)
Step 2  地支关系图谱  ← v2 关键基础设施(子平引擎当前没有)
          检测:六冲 / 六合 / 三合 / 三会 / 相穿 / 相刑 / 暗合 / 自合(6组)
Step 3  做功识别(模式匹配:顺局4式 + 反局4式 + 自合)
          顺局: 官印相生 / 杀印相生 / 食伤生财 / 印生身
          反局: 食伤制杀 / 印制食伤 / 比劫制杀 / 财星制印
          自合: 体合财官(强者制弱者),体>财官=吉,体<财官=机会多拿不到
          每条做功记: {type, 参与柱位, 元素链, 是否清纯pure, 位置(主位/家外)}
Step 4  主位 vs 家外 + 拿进主位
          家外 = 年月    主位 = 日时(有绝对话语权)
          家外资源 是否 通过 刑/冲/穿/合 与主位发生做功连接? → naJin: true/false
Step 5  层次定级(映射「财富七因素」7 档)
          综合:家外资源大小 × 用神有力否 × 是否拿进主位 × 做功清纯否
          → level ∈ {大格局, 小格局, 打工命, 穷贱命} 的 7 子档
Step 6  破局/冲损扫描
          标记 冲/穿 打散 财源·禄根 的位置(如机主盘巳亥冲)→ fuPanRisk[]
Step 7  输出对象 + 免责 + 流派声明  (禁编码项一律不进对象,见 §五)
```

> 全程**纯函数、不可变**:每步返回新对象,不改 `paipan` 结果。与 `coding-style.md` 一致。

## 二、可量化规则库(直接可编码的确定性部分)

### 2.1 自合表(6 组高应验,确定性匹配)

| 自合柱 | 天干合地支藏干 | 体 vs 财官 | 吉凶倾向 |
|---|---|---|---|
| 壬午 | 壬合午丁 | 比劫(体) vs 正财 | 体>财=得财吉 |
| 戊子 | 戊合子癸 | 比劫(体) vs 正财 | 同上 |
| 丁亥 | 丁合亥壬 | 食伤? vs 官杀 | 看强弱 |
| 己亥 | 己合亥甲 | 比劫 vs 官杀 | 看强弱 |
| 辛巳 | 辛合巳丙 | 比劫 vs 官杀 | 看强弱 |
| 癸巳 | 癸合巳戊 | 比劫 vs 官杀 | 看强弱 |

规则:`体力 > 被合财官力 → 得;反之 → 机会多拿不到`。力量取值用 §2.3 力量表。

### 2.2 做功模式库(8 式十神组合,枚举匹配)

| 局 | 模式 | 识别条件(十神相邻/同柱/做功) |
|---|---|---|
| 顺 | 官印相生 | 官杀 生 印,印贴身 |
| 顺 | 杀印相生 | 七杀 生 印 |
| 顺 | 食伤生财 | 食伤 生 财(机主盘:乙伤→巳丙财) |
| 顺 | 印生身 | 印 生 日主 |
| 反 | 食伤制杀 | 食伤 克 七杀 |
| 反 | 印制食伤 | 印 克 食伤 |
| 反 | 比劫制杀 | 比劫 克 七杀 |
| 反 | 财星制印 | 财 克 印 |

`pure(清纯) = 主位参与 && 无第三元素混杂阻碍`。清纯+拿进主位 = 高层次。

### 2.3 干支力量表 §7(本设计唯一可回灌子平引擎的部分)

来自知识库 §7,5 种单柱组合(盖头/截脚/泄/支生干/一气/自合),给出每柱**量化增减力系数**。
- **可复用价值**:把这套系数接进现有 `wuxingScore.js`,能同时提升**子平打分精度**和**盲派体用力量计算** → 双赢,**优先级最高**。
- 例:`一气(甲寅/乙卯…)双方各 +50%`;`盖头(壬午…)干耗3成支减5成`;`截脚(壬辰…)干减5成`。

## 四、黄金验收锚点 —— 机主盘(最高权威,写死为断言)

> 八字:**壬午 辛亥 壬辰 乙巳**。引擎实现后必须复现下表,偏离即 bug(同子平引擎机主盘锁死逻辑)。

| 字段 | 期望值 |
|---|---|
| 体(工具) | 辛印 + 壬比 + 亥禄 + 乙伤 → **体旺**,有资格做功 |
| 做功① | 食伤生财 @ 时柱乙巳(乙→巳丙),`pure:true`,**主位** |
| 做功② | 自合得财 @ 年柱壬午(壬合午丁),`体>财=得财吉`,**家外** |
| 拿进主位 | `ok:true` —— 壬午自合把家外正财拿进 |
| 破局风险 | **巳亥冲**:时巳冲月亥,财源+禄根被打散 → 财不稳/反复 |
| 层次 | **中上(④⑤档)**,需行火土木运送资源放大 |
| 婚姻(男财为妻) | 妻星丁(午)被自合+巳亥冲 → 感情理想化、易反复,宜 30 后定 |
| 健康速断 | 水火交战+巳亥冲 → 眼目/心血管/睡眠;水寒 → 肾·泌尿·忌寒凉 |

**交叉验证(可信度最高的部分)**:子平(喜火土木)与盲派(行火土木运送资源)**殊途同归指向火土木**,且双方都标记**巳亥冲=反复风险**。这两点双盲一致,落地输出时可重点采信。

## 五、禁编码清单(玄学红线,永不落地为断言)

> 违反 spec 5.2.1.4(禁绝对化)+ CLAUDE.md 玄学红线 + 巴纳姆效应。这些只可作内容素材,**绝不进引擎输出对象**。

- ❌ 身高 / 体型 / 长相 / 五官 100+ 条断语(知识库 §8)
- ❌ 六亲生死、父母寿夭具体断言(§9)
- ❌ 子女数量/性别/血光绝对化(§10)
- ❌ 任何「必定/一定/注定」句式;任何不可证伪的具体事件预测

引擎只输出**结构性倾向**(体用/做功/层次/破局),**不输出宿命断言**。

## 一、总纲:体 · 用 · 顺局 · 反局

### 1.1 体与用

| 概念 | 内涵 |
|---|---|
| **体** | 印、比劫、食伤 —— **求财的工具** |
| **资源(所求)** | 财、官、印、食伤 —— 一切所求之人事物 |
| **用** | 使用工具去得到资源的动作(下节详解) |

通过「用」把「体」组织起来,形成**顺局**或**反局**。

### 1.2 顺局 / 反局(成局条件)

想拥有财富格局,以下至少成立一条,**越清纯越富贵**:

- **顺局(生化)**:官印相生、杀印相生、食伤生财、印星生身
- **反局(制用)**:食伤制杀、印制食伤、比劫制杀、财星制印

格局成立后,再看四柱:能把**年月大财**通过刑冲穿合**拿进主位**,则成富贵格局。

## 二、用 / 喜 / 忌 / 资源

### 2.1 何为「用」(工具)

| 原局出现 | 可用的工具(用神组合) | 现实对应 |
|---|---|---|
| 财星 | 伤生财 / 印制财 | 技术头脑 / 学历贵人 |
| 印 | 财得印 | 花钱买学历/房子/娶妻 |
| 官杀 | 食伤得官杀 | 身体、才华、魅力、手段 |
| 食伤(无财时,食伤可论财) | 印制食伤 / 官杀耗食伤 | 学历贵人知识 / 让食伤运转起来 |

> 从事「用神组合」对应的行业,才能得到所求。

### 2.2 何为「喜」(缺什么五行,来什么运好)

- 喜神**辅助**用神组合;不来喜神依然能赚,只是效率低(100万格局只发挥20万),来喜神运拉满。
- 五种做功效率情形:
  1. 用神被喜神做功 → 效率拉满(100%)
  2. 喜神被忌神做功 → 帮不到用神(效率低但不出事)
  3. 用神被忌神做功 → 直接缺工具(无效率)
  4. 用神喜神反做功+忌神虚弱 → 起反作用(伤筋动骨)
  5. 用神喜神反做功+忌神强旺 → 没工具又制不住忌神(直接玩完)

### 2.3 何为「忌」

- 一切阻碍用神、喜神的神 = 忌神。**忌神身份可随意变换**,喜神也能变忌神。
- 例:壬水食神制杀(寅木制戊土),偏印申金/庚金可为忌;身弱癸水食神制杀,流年金绝用神(乙酉/辛卯/甲申/庚寅),金成大忌,七杀无制克身 → 玩完。

### 2.4 何为「资源」(只论原局,不含大运)

- 忌神被制 → 变资源(**制用资源**):如印旺为忌被制 → 得学历/房产/知识/贵人。
- 喜用生化 → 拿到当资源(**生化资源**):如比劫旺不算资源,弱的财官才是资源。
- **原局决定一生层次,定死高低贵贱,不可改。**

## 三、层次与成格

- **成格**:主位参与 食伤生财 / 食伤制杀 / 杀印相生 / 官印相生 / 伤官配印 / 印制食伤 / 伤官合杀 / 阳刃驾杀,八字清纯做功 = 高层次。
- 有阻碍/元素混杂 → 中层次;杂乱无章无组合 → 低层次。

| 层次 × 运 | 结果 |
|---|---|
| 高层次 + 好运 | 富贵 |
| 高层次 + 差运 | 小富 |
| 中层次 + 好运 | 小康 |
| 中层次 + 差运 | 普通 |
| 低层次 + 好运 | 普通 |
| 低层次 + 差运 | 低贱 |

## 四、主位 vs 家外 + 决定财富七因素

- **年月** = 祖上 / 社会资源(**家外**);**日时** = 家里资源(**主位**,有绝对话语权)。
- 要有钱,必须把家外资源**拿进主位**;拿不进 = 机会多但抓不到,眼红拿不进家。

| # | 年月资源 | 用神 | 做功联系 | 结果 |
|---|---|---|---|---|
| ① | 大 | 得利,拿进主位 | 四柱均做功 | 千万起步,大格局 |
| ② | 大 | 不与年月做功 | 仅日时做功 | 只用主位资源,小格局 |
| ③ | 大 | 与年月做功但无力 | — | 普通人,打工命 |
| ④ | 无 | 主位有资源,用神有力但资源不足 | — | 打工命 |
| ⑤ | 有限 | 主位有限,用神有力资源不足 | — | 打工命 |
| ⑥ | 大 | 用神被伤,皆无力 | — | 拿不进还身残,穷贱命 |
| ⑦ | 无 | 主位资源小,用神有利资源不足 | — | 穷贱命 |

## 五、婚姻篇(正缘判断)

### 5.1 夫妻星取法

- **男命**:财星为妻;正偏财混杂取正财;无财取官杀;无官杀取食伤。
- **女命**:官杀为夫;官杀混杂取正官;无官杀取财星;无财取印。
- 婚姻宫(日支)+ 夫妻星 **必须一起分析**。

### 5.2 婚配基本原则(25条)

**孤寡/无缘(1–4)**
1. 日元弱、地支立不住、原局大运无帮扶 → 孤寡。
2. 日元不弱但配偶星无根立不住、无帮扶 → 孤寡。
3. 原局过阴(金水)或过阳(木火)严重失衡,且行同性运、配偶不现 → 孤寡。
4. 原局不现夫妻星,大运找不到;或夫妻星/宫与日元十二长生互绝 → 犯孤寡。

**正常姻缘与应期(5–10)**
5. 前四条不成立则有正缘;流年与夫妻宫三合/六合可恋爱;夫妻星在年月高透无伤主早恋早婚,被刑冲穿绝破主30/35岁后婚,早婚必离。
6. 地支藏夫妻星,流年天干引出做功 → 可恋爱。
7. 夫妻宫被刑冲穿,流年三合/六合解除 → 可恋爱。
8. 日元弱,运流年喜用帮日元立住做功 → 可恋爱结婚。
9. 日元强、夫妻星虚透/受伤,运流年来帮夫妻星做功 → 可恋爱结婚。
10. 流通好但流年忌神做功使日元转弱/受伤立不住 → 分手。

**透根/受伤与离合(11–15)**
11. 天透怕通根、有根怕透干:恋爱年夫妻星虚透,后续流年地支再现夫妻星 → 易分手。
12. 夫妻星高透,流年来伤(正官高透遇伤官、满伤官遇正官高透)→ 易离婚。
13. 流年引动夫妻宫冲合刑绝破必应事;**结婚必须出现印**(原局无则流年找),且夫妻星要立得住(如辛金需土生或金旺)。
14. 夫妻星与夫妻宫在原局大运流年皆伤 → 必离或单身。
15. 过阴/过阳者走协调运,即便不与婚姻宫做功,与夫妻星做功也可婚。

**二婚/家外有家/白头(16–25)**
16. 婚姻宫双显(如未土再现)= 伏吟重复相 → 定二婚。
17. 原局两夫妻星且一柱与日柱地支做功 → 结一次婚;刑穿破婚姻宫一次离一次;第二段是否幸福看第二夫妻星与婚姻宫是否相合(合白头、破绝冲离散、穿多因子女/利益维系)。
18. 正偏财混杂/官杀混杂、无印或印伤、身不弱、皆与婚姻宫联系 → 家外有家/养小三/吃快餐。
19. 只一个夫妻星、婚姻宫不伤、与夫妻星天合地合自合三者之一 → 白头偕老。
20. 男重肉体女重感情;流年透夫妻星与原局婚姻宫/夫妻星做功 = 出轨,但未必离;离要看婚姻宫与夫妻星双毁 + 印星透落/受伤(主分居离婚)。
21. 夫妻星天透地藏坐财库/强根/生助(辛丑辛酉等):坐印=配偶家有钱,落强根=配偶能力强 → 嫁贵夫/娶豪门。
22. 夫妻星不透干 → 家境一般;再受刑冲穿绝破 → 能力不佳家境平庸。
23. 夫妻星/宫为喜用 → 婚后财运越来越好;为忌 → 感情一般有隔阂。
24. 婚姻宫为夫妻星长生/沐浴/帝旺/临官 → 旺妻旺夫;落衰病死墓 → 不利配偶健康财运;落绝 → 不易成婚或分居离异。
25. 夫妻星/宫与忌神或比劫做功 → 配偶或自己出轨/藕断丝连。

## 八、太极点 / 身高长相(参考,禁编码为断言)

### 8.1 五行体型法

```
木瘦 金方 水主肥,土形敦厚背如龟,上尖下阔名为火
```
- 木火旺水土少 → 中等偏瘦(木为食伤多秀美);水土旺木火少 → 中等偏胖。
- 土:燥土(未戌)肌肉型胖,湿土(辰丑)脂肪型胖。
- 偏瘦组合:木旺克土、水火克战、火金、阳木阴火。
- 偏胖组合:两行相生一气(金水/水木/木火/火土/土金),正印正财正官食伤比禄最易胖。

### 8.2 日主身高法(旧断法+10cm)

| 日主 | 身高倾向 |
|---|---|
| 木 | 高(生发) |
| 火 | 中等(漂浮) |
| 土 | 矮(被踩脚下) |
| 金 | 高(可拉伸) |
| 水 | 高(可流动) |

> 示例案例:乾造 壬辛甲癸/申亥寅酉,少年运壬子癸丑 → 断 183(应验)。

### 8.3 十神体型法(摘)

## 九、六亲法

### 9.1 缘分深浅总则

## 十、子女法

### 10.1 子女星取法

- **男命**:有财以七杀为儿、正官为女;无财以食神为儿、伤官为女;无官杀食伤则以时柱论。
- **女命**:伤官为儿、食神为女。
- 食伤个数 ≈ 胎数(含流产堕胎计划),非实际生育数。
- 总纲:宫位 → 子女星 → 太极点 → 原局/月令/大运对子女星生克 → 定性别、是否有子女、是否有出息、能否进家门。

### 10.2 先后与有无(8条)

1. 男命:官旺实忌无女、杀旺实忌无男;七杀被食神克坏无男、正官被伤官克坏无女。女命:食神受克女不先出生、伤官受克儿不先出生。
2. 男命子女宫伤官无女/食神无儿;女命子女宫偏印无女/正印无儿 —— 不受克者先出生。
3. 月令(17–32岁)与大运对子女星生克要重视:被克伤者不先出生。
4. 男命官杀混杂俱忌,近日干者为真忌无缘(正官近=无女、七杀近=无儿)。
5. 女命食伤混杂俱旺,坐支最近(次月干时干),盗泄日干者为实忌无缘。
6. 只现一个子女星:不被克则该性别先出生;被克则未现的那个先出生。
7. 俱不受克:男命得相生者先、女命得日干相生者先。
8. 子女宫刑穿子女星 → 被刑者流产/不好养;子女星为忌无解 → 可能无子;为喜而虚 → 难有子。

### 10.3 有出息 / 好养(摘)

- 官杀不为忌且得生助 → 后代兴旺有出息;不为忌不受伤流通有情 → 兴旺。
- 时支/食伤逢刑冲 → 子女不享福/不和睦;为用神 → 贤孝有助。
- 坐长生子长寿、坐华盖聪明孤独缘薄、坐墓死绝多疾、坐帝旺临官荣华。
- 男命多食伤损子(伤官极旺损长子);女命伤官坐空亡损子(逢合不论)。

### 10.4 女命生育血光(盲派补充)

- 时干枭+时支阳刃 → 多流产开刀。
- 日主坐阳刃为忌 → 子宫开刀刮宫流产(应期:阳刃逢冲值合岁运)。
- 日时柱逢冲 → 易流产堕胎(宜放时柱/日主逢合年生育)。
